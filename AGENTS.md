# AGENTS.md

Перед любой правкой полностью прочитай `CLAUDE.md`, затем относящийся к задаче
шаг в `docs/tz.md`. `CLAUDE.md` — источник инвариантов; `docs/tz.md` —
контракт реализации и приёмки.

Ответы и проектная документация — на русском. Выполняй один шаг ТЗ за раз,
после него запускай build и tests, перечисляй изменённые файлы и останавливайся
до подтверждения пользователя.

Для фильтров universe не отступай от модели
`snapshot → screen → alpha`: POST меняет сохранённое состояние конкретного
фильтра, GET только читает текущую композицию.
